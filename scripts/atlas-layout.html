AI engineer take-home

The assignment.

Build a local assistant that helps a shipping analyst check how to prepare and clean a cargo hold.

The analyst asks in English. Each answer points to the exact passage in a public manual. When the manual leaves a question open, the assistant says what it couldn’t establish.

Read the original brief → Try the assistant ↗

What to deliver

  1. A working assistant

    Choose one or two public sources. Build a local question form and API that retrieve relevant passages and use them to generate a cited answer.

  2. Two checked answers

    Run one question the source answers and one it leaves open. Save the passages and responses, then judge each result against what you expected.

  3. A ten-minute walkthrough

    Share a runnable repository and README. Explain a trade-off, a limitation and the first three improvements you would make for a pilot.

Time budget and scoring

Aim for 3–4 hours of preparation. Stop at 5 hours. The live review lasts 60 minutes.
